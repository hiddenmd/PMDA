# Attitude 3D Chase View + Glass ADI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the Attitude panel's hand-projected 2D aircraft with a lazy-loaded three.js chase view in the
Tactical render look, using aircraft models we author. Redraw the ADI as a glass instrument overlaid on the
scene.

**Architecture:**

- Pure frame maths (`scene3d/frame.ts`) turns attitude and track samples into three.js orientations,
  local positions, the trail and camera offsets. It is unit-tested.
- A Node build script authors the jet and helicopter and exports `.glb` files into `web/public/models`.
- `scene3d/ChaseScene.ts` owns the WebGL renderer, scene, models, trail and camera, and renders on demand.
  `createChaseScene` returns `null` without WebGL.
- `AttitudeView` dynamic-imports it, so three.js stays out of the main chunk. It lays the scene out with the
  ADI overlaid and keeps the 2D drawing as a fallback.

**Tech Stack:** React 19, TypeScript 5.9, Vite 8, Vitest 4 (jsdom; `// @vitest-environment node` where
noted), three.js 0.186 (`three`, `@types/three`), plain CSS.

**Spec:** `docs/superpowers/specs/2026-10-19-attitude-3d-design.md` (builds on
`docs/superpowers/specs/2026-10-19-tactical-hud-redesign.md`).

## Global Constraints

- **Frames:**
  - Local scene frame: x = east, y = up, z = south (−z = north), metres.
  - Model frame: −Z forward (nose), +Y up, +X right wing.
  - Heading is degrees true, clockwise from north. Pitch is positive nose-up; roll is positive right wing
    down.
- **Orientation:** `Euler(pitch·rad, −heading·rad, −roll·rad, 'YXZ')`.
- **Camera presets** (distance, azimuth relative to the aircraft's tail, elevation):

  | Preset | Distance | Azimuth | Elevation | Notes |
  |---|---|---|---|---|
  | Chase | 18.66 m | 22.36° | 9.87° | = offset (7, 3.2, 17) behind-right-above at heading 0 |
  | Side | 22 m | 90° | 0° | |
  | Top | 40 m | 0° | 89° | north-up: azimuth is not relative to heading |

  Orbit adds yaw (any) and pitch, with elevation clamped to −10°…89°. Damping factor `1 − 0.05^dt`
  (dt in s); reduced motion snaps.
- **Trail:** the last 60 000 ms up to the playhead, at most 240 points, newest last.
- **Rotors:** main 6 rev/s, tail 30 rev/s; ×0.25 under `prefers-reduced-motion: reduce`.
- **Colours** come from CSS tokens, re-read when `data-theme` changes:
  - scene background/fog `--color-background`;
  - grid `--color-border-strong` / `--color-border`;
  - edges, rim light and trail `--color-primary`.

  The aircraft body is `#8b97a8` (metalness 0.55, roughness 0.45) and the canopy `#1b2a40`.
- **Glass ADI:**
  - Sky gradient `#3c82c4` (horizon) → `#1f5a94` (top).
  - Ground `#6b4423` (horizon) → `#4a2f17` (bottom).
  - Ladder every 2.5°, labelled every 10°.
  - Amber aircraft symbol and bank pointer (`symbol`), with a centred slip trapezoid under the pointer.
  - Cyan lubber line on the heading tape (`accent` = `--color-primary`).
  - No flight-path marker.
- **Build and bundle:** three.js must be imported only inside `src/features/attitude/scene3d/**` and loaded
  by dynamic `import()`. `index-*.js` must not contain three.
- **Models:** `web/public/models/jet.glb` and `helicopter.glb`, generated by
  `npm --prefix web run build:models` and committed. Node names `Body`, `Canopy`, `MainRotor`, `TailRotor`.
- **Commands** from the repo root C:\PMDA: `npm --prefix web run typecheck`, `npm --prefix web run lint`
  (0 warnings), `npm --prefix web test`, `npm --prefix web run build`.
- **Commits** end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

```ts
import { Euler, Quaternion, Vector3 } from 'three'
import type { FlightTrack } from '../../../api/types'
import { positionAt, sampleIndex, type TrackPoint } from '../../map/track'

const RAD = Math.PI / 180
const EARTH_RADIUS_M = 6_371_000

/**
 * Orientation of a model whose nose is −Z, up +Y and right wing +X, in the local frame
 * (x east, y up, z south): heading turns it about +Y, then pitch about X, then roll about Z.
 */
export function attitudeQuaternion(pitch: number, roll: number, heading: number): Quaternion {
  return new Quaternion().setFromEuler(new Euler(pitch * RAD, -heading * RAD, -roll * RAD, 'YXZ'))
}

/** `p` in metres from `origin`: x east, y up, z south (equirectangular; fine over a few km). */
export function toLocal(origin: TrackPoint, p: TrackPoint): [number, number, number] {
  const x = (p.lon - origin.lon) * RAD * EARTH_RADIUS_M * Math.cos(origin.lat * RAD)
  const z = -(p.lat - origin.lat) * RAD * EARTH_RADIUS_M
  return [x, p.altM - origin.altM, z]
}

/**
 * The flown path over the `windowMs` before `ms`, as xyz triples relative to the position at `ms`,
 * newest last and ending exactly at the playhead; at most `max` points (older samples thinned).
 */
export function trailPoints(track: FlightTrack, ms: number, windowMs = 60_000, max = 240): Float32Array {
  const here = positionAt(track, ms)
  if (!here) return new Float32Array(0)
  const last = sampleIndex(track, ms)
  let first = last
  while (first > 0 && track.t[first - 1] >= ms - windowMs) first--
  const indexes: number[] = []
  if (last >= 0) for (let i = Math.max(first, 0); i <= last; i++) if (track.t[i] >= ms - windowMs) indexes.push(i)
  const room = max - 1 // the playhead point is always kept
  const stride = Math.max(1, Math.ceil(indexes.length / room))
  const kept = indexes.filter((_, k) => (indexes.length - 1 - k) % stride === 0)
  const out = new Float32Array((kept.length + 1) * 3)
  kept.forEach((i, k) => out.set(toLocal(here, { lat: track.lat[i], lon: track.lon[i], altM: track.altM[i] }), k * 3))
  out.set([0, 0, 0], kept.length * 3)
  return out
}

export type CameraPreset = 'chase' | 'side' | 'top'

/** Distance (m), azimuth from the tail (deg, + to the right) and elevation (deg) of each preset. */
const PRESETS: Record<CameraPreset, { d: number; az: number; el: number; northUp?: boolean }> = {
  chase: { d: Math.hypot(7, 3.2, 17), az: Math.atan2(7, 17) / RAD, el: Math.asin(3.2 / Math.hypot(7, 3.2, 17)) / RAD },
  side: { d: 22, az: 90, el: 0 },
  top: { d: 40, az: 0, el: 89, northUp: true },
}

/** Camera position relative to the aircraft, in the local frame, for a preset plus the user's orbit (deg). */
export function cameraOffset(preset: CameraPreset, headingDeg: number, orbit: { yaw: number; pitch: number }): Vector3 {
  const p = PRESETS[preset]
  const az = (p.az - (p.northUp ? 0 : headingDeg) + orbit.yaw) * RAD
  const el = Math.min(89, Math.max(-10, p.el + orbit.pitch)) * RAD
  return new Vector3(Math.cos(el) * Math.sin(az), Math.sin(el), Math.cos(el) * Math.cos(az)).multiplyScalar(p.d)
}

/** Fraction of the remaining distance to cover this frame for exponential damping. */
export const damp = (rateBase: number, dtSec: number) => 1 - rateBase ** dtSec
```

```js
/**
 * Authors PMDA's aircraft models with three.js geometry and writes them as binary glTF to public/models.
 * Frame: −Z forward (nose), +Y up, +X right wing, metres; origin near the centre of gravity.
 * Materials are placeholders: the app assigns its own by node name (Body, Canopy, MainRotor, TailRotor).
 * Run: npm --prefix web run build:models
 */
import { mkdirSync, writeFileSync } from 'node:fs'
import { dirname, join } from 'node:path'
import { fileURLToPath } from 'node:url'
import * as THREE from 'three'
import { GLTFExporter } from 'three/examples/jsm/exporters/GLTFExporter.js'

// GLTFExporter reads Blobs with FileReader, which Node lacks.
globalThis.FileReader ??= class {
  readAsArrayBuffer(blob) {
    blob.arrayBuffer().then((r) => {
      this.result = r
      this.onloadend?.()
    })
  }
  readAsDataURL(blob) {
    blob.arrayBuffer().then((r) => {
      this.result = `data:${blob.type || 'application/octet-stream'};base64,${Buffer.from(r).toString('base64')}`
      this.onloadend?.()
    })
  }
}

const out = join(dirname(fileURLToPath(import.meta.url)), '..', 'public', 'models')
const grey = new THREE.MeshStandardMaterial({ color: 0x8b97a8, metalness: 0.55, roughness: 0.45 })
const glass = new THREE.MeshStandardMaterial({ color: 0x1b2a40, metalness: 0.2, roughness: 0.1 })

const mesh = (geometry, name, material = grey) => Object.assign(new THREE.Mesh(geometry, material), { name })

/** Body of revolution along −Z from a profile of [z, radius] pairs (z increasing = aft). */
function lathe(profile, segments = 24) {
  const pts = profile.map(([z, r]) => new THREE.Vector2(Math.max(r, 0.001), z))
  const g = new THREE.LatheGeometry(pts, segments)
  g.rotateX(Math.PI / 2) // lathe axis Y → Z
  g.rotateX(Math.PI) // keep the profile's z sign: −Z forward
  return g
}

/** Flat plate in the XZ plane from [x, z] points, `thick` metres thick, centred on y. */
function plate(points, thick) {
  const shape = new THREE.Shape(points.map(([x, z]) => new THREE.Vector2(x, z)))
  const g = new THREE.ExtrudeGeometry(shape, { depth: thick, bevelEnabled: true, bevelThickness: thick * 0.3, bevelSize: thick * 0.3, bevelSegments: 1 })
  g.rotateX(Math.PI / 2) // shape y → world z, extrusion → −y
  g.translate(0, thick / 2, 0)
  return g
}

/** Vertical plate in the YZ plane from [z, y] points (a fin), `thick` metres thick. */
function fin(points, thick) {
  const shape = new THREE.Shape(points.map(([z, y]) => new THREE.Vector2(z, y)))
  const g = new THREE.ExtrudeGeometry(shape, { depth: thick, bevelEnabled: false })
  g.rotateY(-Math.PI / 2) // shape x → world z
  g.translate(thick / 2, 0, 0)
  return g
}

const mirrorX = (points) => points.map(([x, z]) => [-x, z])

function jet() {
  const root = new THREE.Group()
  root.name = 'Jet'
  const body = new THREE.Group()
  body.name = 'Body'
  root.add(body)
  // Fuselage: pointed nose at z −8.5, widest at the intakes, tapering to the nozzle at z +7.
  body.add(mesh(lathe([[-8.5, 0], [-7.6, 0.28], [-6, 0.62], [-3.5, 0.9], [0, 1], [4, 0.9], [6.4, 0.68], [7, 0.62]]), 'Fuselage'))
  const nozzle = new THREE.CylinderGeometry(0.58, 0.5, 0.9, 20, 1, true)
  nozzle.rotateX(Math.PI / 2)
  nozzle.translate(0, 0, 7.4)
  body.add(mesh(nozzle, 'Nozzle'))
  for (const side of [1, -1]) {
    const intake = new THREE.BoxGeometry(0.7, 0.9, 4.2)
    intake.translate(side * 1.05, -0.15, -1.6)
    body.add(mesh(intake, side > 0 ? 'IntakeRight' : 'IntakeLeft'))
  }
  const wing = [[0.9, -2.2], [5.1, 2.4], [5.1, 3.4], [0.9, 3.6]]
  body.add(mesh(plate(wing, 0.16), 'WingRight'))
  body.add(mesh(plate(mirrorX(wing), 0.16), 'WingLeft'))
  const tail = [[0.7, 4.6], [2.8, 6.4], [2.8, 7.2], [0.7, 7.3]]
  body.add(mesh(plate(tail, 0.1), 'TailplaneRight'))
  body.add(mesh(plate(mirrorX(tail), 0.1), 'TailplaneLeft'))
  const finGeo = fin([[3.2, 0.6], [6.4, 3.6], [7.3, 3.6], [7.2, 0.6]], 0.14)
  body.add(mesh(finGeo, 'Fin'))
  const canopy = new THREE.SphereGeometry(0.62, 24, 12, 0, Math.PI * 2, 0, Math.PI / 2)
  canopy.scale(1, 0.85, 2.6)
  canopy.translate(0, 0.62, -4.6)
  root.add(mesh(canopy, 'Canopy', glass))
  return root
}

function helicopter() {
  const root = new THREE.Group()
  root.name = 'Helicopter'
  const body = new THREE.Group()
  body.name = 'Body'
  root.add(body)
  body.add(mesh(lathe([[-3.4, 0], [-3.1, 0.6], [-2.2, 1.05], [0, 1.15], [1.6, 1.0], [2.6, 0.55], [3.2, 0.3]]), 'Cabin'))
  const boom = new THREE.CylinderGeometry(0.16, 0.32, 5.6, 14)
  boom.rotateX(Math.PI / 2)
```

```ts
import * as THREE from 'three'
import { GLTFLoader } from 'three/examples/jsm/loaders/GLTFLoader.js'
import type { FlightTrack } from '../../../api/types'
import type { Attitude } from '../attitude'
import { positionAt } from '../../map/track'
import { attitudeQuaternion, cameraOffset, damp, toLocal, trailPoints, type CameraPreset } from './frame'

export interface SceneColors {
  background: string
  grid: string
  gridMinor: string
  accent: string
}
export interface ChaseFrame {
  attitude: Attitude
  track: FlightTrack
  ms: number
}
export interface ChaseScene {
  setFrame(frame: ChaseFrame): void
  setPreset(preset: CameraPreset): void
  orbitBy(dYawDeg: number, dPitchDeg: number): void
  resetView(): void
  setColors(colors: SceneColors): void
  resize(width: number, height: number, pixelRatio: number): void
  render(nowMs: number): boolean
  dispose(): void
}

const MODEL_URL = { FixedWing: '/models/jet.glb', Helicopter: '/models/helicopter.glb' } as const
const TRAIL_MAX = 240
const MAIN_REV_S = 6
const TAIL_REV_S = 30
const DAMPING_BASE = 0.05
const GRID_SIZE = 600
const GRID_CELL = 10

/** A chase view of the aircraft at the playhead; null where WebGL is unavailable (the caller falls back to 2D). */
export async function createChaseScene(
  canvas: HTMLCanvasElement,
  platform: 'FixedWing' | 'Helicopter',
  reducedMotion: boolean,
): Promise<ChaseScene | null> {
  if (typeof WebGL2RenderingContext === 'undefined') return null
  let renderer: THREE.WebGLRenderer
  try {
    renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: false })
  } catch {
    return null
  }
  const gltf = await new GLTFLoader().loadAsync(MODEL_URL[platform])
  return new Scene(renderer, gltf.scene, reducedMotion)
}

class Scene implements ChaseScene {
  private scene = new THREE.Scene()
  private camera = new THREE.PerspectiveCamera(42, 1, 0.1, 2000)
  private aircraft = new THREE.Group()
  private body = new THREE.MeshStandardMaterial({ color: 0x8b97a8, metalness: 0.55, roughness: 0.45 })
  private glass = new THREE.MeshStandardMaterial({ color: 0x1b2a40, metalness: 0.2, roughness: 0.1 })
  private edges = new THREE.LineBasicMaterial({ transparent: true, opacity: 0.75 })
  private rim = new THREE.DirectionalLight(0xffffff, 2.2)
  private grid: THREE.GridHelper | null = null
  private trailGeometry = new THREE.BufferGeometry()
  private trailMaterial = new THREE.LineBasicMaterial({ vertexColors: true, transparent: true, opacity: 0.9 })
  private mainRotor: THREE.Object3D | null
  private tailRotor: THREE.Object3D | null
  private preset: CameraPreset = 'chase'
  private orbit = { yaw: 0, pitch: 0 }
  private heading = 0
  private camOffset: THREE.Vector3 | null = null
  private colors: SceneColors = { background: '#080b12', grid: '#22324d', gridMinor: '#1a2436', accent: '#4cc3ff' }
  private lastNow = 0
  private dirty = true

  constructor(
    private renderer: THREE.WebGLRenderer,
    model: THREE.Object3D,
    private reducedMotion: boolean,
  ) {
    this.scene.add(new THREE.HemisphereLight(0x6b8fbf, 0x080b12, 0.9))
    const key = new THREE.DirectionalLight(0xffffff, 0.9)
    key.position.set(8, 12, -6)
    this.scene.add(key)
    this.rim.position.set(-10, 6, 14)
    this.scene.add(this.rim)

    model.traverse((o) => {
      if (!(o instanceof THREE.Mesh)) return
      const isCanopy = o.name === 'Canopy' || o.parent?.name === 'Canopy'
      o.material = isCanopy ? this.glass : this.body
      if (!isCanopy) o.add(new THREE.LineSegments(new THREE.EdgesGeometry(o.geometry, 25), this.edges))
    })
    this.mainRotor = model.getObjectByName('MainRotor') ?? null
    this.tailRotor = model.getObjectByName('TailRotor') ?? null
    this.aircraft.add(model)
    this.scene.add(this.aircraft)

    this.trailGeometry.setAttribute('position', new THREE.BufferAttribute(new Float32Array(TRAIL_MAX * 3), 3))
    this.trailGeometry.setAttribute('color', new THREE.BufferAttribute(new Float32Array(TRAIL_MAX * 3), 3))
    this.trailGeometry.setDrawRange(0, 0)
    this.scene.add(new THREE.Line(this.trailGeometry, this.trailMaterial))
    this.applyColors()
  }

  setFrame({ attitude, track, ms }: ChaseFrame) {
    this.aircraft.quaternion.copy(attitudeQuaternion(attitude.pitch, attitude.roll, attitude.heading))
    this.heading = attitude.heading
    // The aircraft stays at the origin; the trail and grid move around it (no float drift on long flights).
    // The grid shifts by the distance flown modulo one cell, so the ground visibly passes underneath.
    const start = positionAt(track, track.t[0] ?? 0)
    const here = positionAt(track, ms)
    if (start && here && this.grid) {
      const [x, , z] = toLocal(start, here)
      const wrap = (v: number) => ((v % GRID_CELL) + GRID_CELL) % GRID_CELL
      this.grid.position.x = -wrap(x)
      this.grid.position.z = -wrap(z)
    }
    const pts = trailPoints(track, ms, 60_000, TRAIL_MAX)
    const pos = this.trailGeometry.getAttribute('position') as THREE.BufferAttribute
    pos.array.set(pts)
    pos.needsUpdate = true
    const n = pts.length / 3
    this.trailGeometry.setDrawRange(0, n)
    this.paintTrail(n)
    this.dirty = true
  }

  setPreset(preset: CameraPreset) {
    this.preset = preset
    this.orbit = { yaw: 0, pitch: 0 }
    this.dirty = true
  }

  orbitBy(dYawDeg: number, dPitchDeg: number) {
    this.orbit = { yaw: this.orbit.yaw + dYawDeg, pitch: Math.max(-99, Math.min(99, this.orbit.pitch + dPitchDeg)) }
    this.dirty = true
  }

  resetView() {
    this.setPreset(this.preset)
  }

  setColors(colors: SceneColors) {
    this.colors = colors
    this.applyColors()
    this.dirty = true
  }

  resize(width: number, height: number, pixelRatio: number) {
    this.renderer.setPixelRatio(pixelRatio)
    this.renderer.setSize(width, height, false)
    this.camera.aspect = width / Math.max(1, height)
    this.camera.updateProjectionMatrix()
    this.dirty = true
  }

  render(nowMs: number): boolean {
    const dt = this.lastNow ? Math.min(0.1, (nowMs - this.lastNow) / 1000) : 0
    this.lastNow = nowMs
    const spinning = this.mainRotor !== null
    if (spinning) {
      const k = this.reducedMotion ? 0.25 : 1
      this.mainRotor!.rotation.y -= MAIN_REV_S * 2 * Math.PI * dt * k
      if (this.tailRotor) this.tailRotor.rotation.x -= TAIL_REV_S * 2 * Math.PI * dt * k
    }
    const want = cameraOffset(this.preset, this.heading, this.orbit)
    if (!this.camOffset || this.reducedMotion) this.camOffset = want.clone()
    else this.camOffset.lerp(want, damp(DAMPING_BASE, dt))
    const settling = this.camOffset.distanceToSquared(want) > 1e-4
    if (!this.dirty && !settling && !spinning) return false
    this.camera.up.set(0, 1, 0)
    if (this.preset === 'top' && this.orbit.pitch === 0) this.camera.up.set(0, 0, -1) // north-up
    this.camera.position.copy(this.camOffset)
    this.camera.lookAt(0, 0.5, 0)
    this.renderer.render(this.scene, this.camera)
    this.dirty = false
    return settling || spinning
  }

  dispose() {
    this.scene.traverse((o) => {
      if (o instanceof THREE.Mesh || o instanceof THREE.LineSegments || o instanceof THREE.Line) o.geometry.dispose()
    })
    for (const m of [this.body, this.glass, this.edges, this.trailMaterial]) m.dispose()
    this.grid?.dispose()
    this.renderer.dispose()
  }

  private applyColors() {
    const bg = new THREE.Color(this.colors.background)
    this.scene.background = bg
    this.scene.fog = new THREE.Fog(bg, 40, 180)
    this.edges.color.set(this.colors.accent)
    this.rim.color.set(this.colors.accent)
    if (this.grid) {
      this.scene.remove(this.grid)
      this.grid.dispose()
    }
    this.grid = new THREE.GridHelper(GRID_SIZE, GRID_SIZE / GRID_CELL, this.colors.grid, this.colors.gridMinor)
    this.grid.position.y = -6
    this.scene.add(this.grid)
    this.paintTrail(this.trailGeometry.drawRange.count)
  }

  /** Trail colour fades from the background (oldest) to the accent (newest). */
  private paintTrail(n: number) {
    const col = this.trailGeometry.getAttribute('color') as THREE.BufferAttribute
    const from = new THREE.Color(this.colors.background)
    const to = new THREE.Color(this.colors.accent)
    for (let i = 0; i < n; i++) {
      const c = from.clone().lerp(to, n > 1 ? i / (n - 1) : 1)
      col.setXYZ(i, c.r, c.g, c.b)
    }
    col.needsUpdate = true
  }
}
```

```tsx
import type { CameraPreset } from './scene3d/frame'

/** Instrument colours are the same in both themes, like the real thing; the frame around them follows the theme. */
const INSTRUMENT = { sky: '#3c82c4', skyHigh: '#1f5a94', ground: '#6b4423', groundLow: '#4a2f17', line: '#f4f4f5', symbol: '#fbbf24' }
const MODEL: Omit<ModelColors, 'grid'> = { body: '#b4bcc8', wing: '#8f99a6', canopy: '#3d6286', rotor: '#a3acb8' }
const READOUT_EVERY_MS = 100
const PRESETS: { id: CameraPreset; label: string }[] = [
  { id: 'chase', label: 'Chase' },
  { id: 'side', label: 'Side' },
  { id: 'top', label: 'Top' },
]
/** Degrees of orbit per pixel dragged. */
const ORBIT_PER_PX = 0.4

export type AttitudeReadout = Partial<Record<keyof Attitude, HTMLElement | null>>

interface AttitudeViewProps {
  actor: PlaybackActor
  series: AttitudeSeries
  track: FlightTrack
  platform: 'FixedWing' | 'Helicopter'
  readout: React.RefObject<AttitudeReadout>
}

const sign = (v: number, digits: number) => {
  const text = Math.abs(v).toFixed(digits)
  return Number(text) === 0 ? text : `${v > 0 ? '+' : '−'}${text}`
}
const FORMAT: Record<keyof Attitude, (v: number) => string> = {
  pitch: (v) => `${sign(v, 1)}°`,
  roll: (v) => (Math.abs(v) < 0.5 ? '0°' : `${Math.abs(v).toFixed(1)}° ${v > 0 ? 'R' : 'L'}`),
  heading: (v) => `${Math.round(v) % 360}`.padStart(3, '0') + '°',
  rollRate: (v) => `${sign(v, 1)}°/s`,
  pitchRate: (v) => `${sign(v, 1)}°/s`,
  turnRate: (v) => `${sign(v, 1)}°/s`,
  verticalSpeed: (v) => `${sign(Math.round((v * 196.85) / 10) * 10, 0)} ft/min`,
  groundSpeed: (v) => `${Math.round(v * 1.943844)} kt`,
  loadFactor: (v) => `${v.toFixed(2)} g`,
}

/**
 * The aircraft in a 3D chase view (three.js, loaded on first use) with a glass attitude indicator and
 * heading tape over it, all following the playhead in one animation-frame loop (no React re-render
 * during playback). Where WebGL is unavailable the aircraft is drawn in 2D as before.
 */
export function AttitudeView({ actor, series, track, platform, readout }: AttitudeViewProps) {
  const stageRef = useRef<HTMLDivElement>(null)
  const sceneCanvasRef = useRef<HTMLCanvasElement>(null)
  const adiRef = useRef<HTMLCanvasElement>(null)
  const tapeRef = useRef<HTMLCanvasElement>(null)
  const sceneRef = useRef<ChaseScene | null>(null)
  const [preset, setPreset] = useState<CameraPreset>('chase')
  const presetRef = useRef<CameraPreset>('chase')
  const kickRef = useRef<() => void>(() => {})

  useEffect(() => {
    presetRef.current = preset
    sceneRef.current?.setPreset(preset)
    kickRef.current()
  }, [preset])

  useEffect(() => {
    const sceneCanvas = sceneCanvasRef.current!
    const adi = adiRef.current!
    const tape = tapeRef.current!
    const adiCtx = adi.getContext('2d')
    const tapeCtx = tape.getContext('2d')
    if (!adiCtx || !tapeCtx) return
    const reducedMotion = window.matchMedia?.('(prefers-reduced-motion: reduce)').matches ?? false
    let disposed = false
    let fallbackCtx: CanvasRenderingContext2D | null = null
    let visible = true
    let dirty = true
    let handle = 0
    let lastPosition = -1
    let lastReadout = Number.NEGATIVE_INFINITY
    let readoutStale = false
    const size = new Map<HTMLCanvasElement, { w: number; h: number }>()

    const token = (name: string) => getComputedStyle(stageRef.current!).getPropertyValue(name).trim()
    const sceneColors = () => ({ background: token('--color-background'), grid: token('--color-border-strong'), gridMinor: token('--color-border'), accent: token('--color-primary') })

    const fit = (canvas: HTMLCanvasElement, ctx: CanvasRenderingContext2D | null) => {
      const dpr = window.devicePixelRatio || 1
      const rect = canvas.getBoundingClientRect()
      size.set(canvas, { w: rect.width, h: rect.height })
      if (canvas === sceneCanvas && sceneRef.current) {
        sceneRef.current.resize(rect.width, rect.height, Math.min(dpr, 2))
        return
      }
      canvas.width = Math.max(1, Math.round(rect.width * dpr))
      canvas.height = Math.max(1, Math.round(rect.height * dpr))
      ctx?.setTransform(dpr, 0, 0, dpr, 0, 0)
    }
    const resize = () => {
      fit(adi, adiCtx)
      fit(tape, tapeCtx)
      fit(sceneCanvas, fallbackCtx)
      kick()
    }

    function kick() {
      dirty = true
      if (!handle && visible && !document.hidden) handle = requestAnimationFrame(frame)
    }
    kickRef.current = kick

    // One loop while the view is on screen, as before: reading the playhead is cheap, and the 3D scene
    // only re-renders when its frame, camera damping or rotors need it.
    function frame(now: number) {
      handle = visible && !document.hidden ? requestAnimationFrame(frame) : 0
      const { positionMs } = actor.getSnapshot().context
      const a = attitudeAt(series, positionMs)
      if (a && (positionMs !== lastPosition || dirty)) {
        lastPosition = positionMs
        readoutStale = true
        paintInstruments(a)
        if (sceneRef.current) sceneRef.current.setFrame({ attitude: a, track, ms: positionMs })
        else if (fallbackCtx) paintFallback(a)
      }
      dirty = false
      sceneRef.current?.render(now)
      if (readoutStale && now - lastReadout >= READOUT_EVERY_MS) {
        lastReadout = now
        readoutStale = false
        const r = readout.current
        if (a) for (const key of Object.keys(FORMAT) as (keyof Attitude)[]) if (r[key]) r[key]!.textContent = FORMAT[key](a[key])
      }
    }

    function paintInstruments(a: Attitude) {
      const colors: AdiColors = { ...INSTRUMENT, text: token('--color-foreground'), muted: token('--color-muted-foreground'), bezel: token('--color-border-strong'), accent: token('--color-primary') }
      const s = size.get(adi) ?? { w: 0, h: 0 }
      adiCtx!.clearRect(0, 0, s.w, s.h)
      const r = Math.max(10, Math.min(s.w, s.h) / 2 - 4)
      drawAdi(adiCtx!, s.w / 2, s.h / 2, r, a.pitch, a.roll, colors)
      const t = size.get(tape) ?? { w: 0, h: 0 }
      tapeCtx!.clearRect(0, 0, t.w, t.h)
      drawHeadingTape(tapeCtx!, 0, 0, t.w, t.h, a.heading, colors)
    }

    function paintFallback(a: Attitude) {
      const m = size.get(sceneCanvas) ?? { w: 0, h: 0 }
      fallbackCtx!.clearRect(0, 0, m.w, m.h)
      drawAircraft(fallbackCtx!, m.w / 2, m.h * 0.5, Math.min(m.w, m.h * 1.2), platform, a.pitch, a.roll, { ...MODEL, grid: token('--color-border') })
    }

    void import('./scene3d/ChaseScene')
      .then(({ createChaseScene }) => createChaseScene(sceneCanvas, platform, reducedMotion))
      .catch(() => null)
      .then((scene) => {
        if (disposed) return scene?.dispose()
        if (scene) {
          sceneRef.current = scene
          scene.setColors(sceneColors())
          scene.setPreset(presetRef.current)
        } else {
          fallbackCtx = sceneCanvas.getContext('2d')
        }
        resize()
      })

    resize()
    const resizeObserver = new ResizeObserver(resize)
    ;[adi, tape, sceneCanvas].forEach((c) => resizeObserver.observe(c))
    const visibility = new IntersectionObserver(([entry]) => {
      visible = entry?.isIntersecting ?? true
      if (visible) kick()
    })
    visibility.observe(stageRef.current!)
    const onPageVisibility = () => !document.hidden && kick()
    document.addEventListener('visibilitychange', onPageVisibility)
    const themeObserver = new MutationObserver(() => {
      sceneRef.current?.setColors(sceneColors())
      kick()
    })
    themeObserver.observe(document.documentElement, { attributes: true, attributeFilter: ['data-theme'] })

    // Drag to orbit, double-click to reset.
    let drag: { x: number; y: number } | null = null
    const down = (e: PointerEvent) => {
      drag = { x: e.clientX, y: e.clientY }
      sceneCanvas.setPointerCapture?.(e.pointerId)
    }
    const move = (e: PointerEvent) => {
      if (!drag || !sceneRef.current) return
      sceneRef.current.orbitBy(-(e.clientX - drag.x) * ORBIT_PER_PX, (e.clientY - drag.y) * ORBIT_PER_PX)
      drag = { x: e.clientX, y: e.clientY }
      kick()
    }
    const up = () => (drag = null)
    const reset = () => {
      sceneRef.current?.resetView()
      kick()
    }
    sceneCanvas.addEventListener('pointerdown', down)
    sceneCanvas.addEventListener('pointermove', move)
    sceneCanvas.addEventListener('pointerup', up)
    sceneCanvas.addEventListener('pointercancel', up)
    sceneCanvas.addEventListener('dblclick', reset)

    return () => {
      disposed = true
      cancelAnimationFrame(handle)
      resizeObserver.disconnect()
      visibility.disconnect()
      themeObserver.disconnect()
      document.removeEventListener('visibilitychange', onPageVisibility)
      sceneCanvas.removeEventListener('pointerdown', down)
      sceneCanvas.removeEventListener('pointermove', move)
      sceneCanvas.removeEventListener('pointerup', up)
      sceneCanvas.removeEventListener('pointercancel', up)
      sceneCanvas.removeEventListener('dblclick', reset)
      sceneRef.current?.dispose()
      sceneRef.current = null
      kickRef.current = () => {}
    }
  }, [actor, series, track, platform, readout])

  return (
    <div className="attitude-view" ref={stageRef}>
      <canvas ref={sceneCanvasRef} className="attitude-view__scene" role="img" aria-label="Aircraft seen from behind, pitched and banked as at the playhead, with its recent flight path" />
      <canvas ref={tapeRef} className="attitude-view__tape" role="img" aria-label="Heading tape at the playhead" />
      <div className="attitude-view__adi-card">
        <canvas ref={adiRef} className="attitude-view__adi" role="img" aria-label="Attitude indicator: pitch and bank at the playhead" />
      </div>
      <div className="attitude-view__toolbar">
        <div className="segmented" role="group" aria-label="Camera view">
          {PRESETS.map((p) => (
            <button key={p.id} type="button" aria-pressed={preset === p.id} onClick={() => setPreset(p.id)}>
              {p.label}
            </button>
          ))}
        </div>
        <button
          type="button"
          className="btn btn--ghost btn--icon btn--compact"
          aria-label="Reset view"
          title="Reset view (or double-click the view)"
          onClick={() => {
            sceneRef.current?.resetView()
            kickRef.current()
          }}
        >
          <RotateCcw size={16} aria-hidden />
        </button>
      </div>
    </div>
  )
}
```

Implementer notes:
- **Camera preset:** the preset reaches the scene through `presetRef` (its own effect) so changing it never
  re-creates the scene or reloads the model. If lint flags the effect's dependency list, that rule is the
  reason; keep the list as written and say so in the report rather than adding `preset`.
